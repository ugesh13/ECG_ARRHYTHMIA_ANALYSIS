# CANDIDATE RESEARCH PAPER TITLES

**Target Focus:** Classical Machine Learning ECG Arrhythmia Classification Benchmark  
**Database:** PhysioNet MIT-BIH Arrhythmia Database (`mitdb`)  
**Standard:** ANSI/AAMI EC57:1998  

---

The following 8 title options are formulated using precise, conservative scientific terminology suitable for publication in biomedical engineering and health informatics journals:

1. **Integrating ECG Morphology and Cardiac Timing Features for Inter-Patient Heartbeat Classification: An AAMI EC57 Benchmark Evaluation on the MIT-BIH Database**  
   *(Recommended: Comprehensive, accurately highlights morphology + timing synergy, AAMI standard, and inter-patient benchmark scope).*

2. **Automated Four-Class ECG Arrhythmia Classification Using Random Forests: Evaluating Morphology and RR-Interval Dynamics on the MIT-BIH Benchmark**  
   *(Focuses on model architecture and feature interaction under the AAMI 4-class taxonomy).*

3. **Evaluating the Contribution of Cardiac Cycle Timing Features to ECG Heartbeat Classification Across Independent Records of the MIT-BIH Arrhythmia Database**  
   *(Emphasizes the central research question regarding the isolated discriminative value of RR timing).*

4. **Inter-Patient Heartbeat Classification Under Extreme Class Imbalance: A Controlled Evaluation of Morphology and Bidirectional RR Features on the MIT-BIH Database**  
   *(Emphasizes the methodological challenges of class imbalance and strict inter-patient data partitioning).*

5. **A Leakage-Aware Machine Learning Benchmark for ECG Arrhythmia Classification: Combining Local Waveform Morphology and Interval Timing**  
   *(Highlights zero-leakage inter-patient experimental design and reproducible methodology).*

6. **Random Forest Classification of ANSI/AAMI EC57 Cardiac Arrhythmias on the MIT-BIH Database: Analysis of Generalization and Timing Feature Importance**  
   *(Focuses on model interpretability, feature importance, and validation-to-test generalization).*

7. **Evaluating Morphological and Temporal Feature Synergy for Retrospective Holter ECG Arrhythmia Classification on the MIT-BIH Database**  
   *(Highlights the practical retrospective / offline Holter monitoring context of bidirectional timing).*

8. **An Inter-Record Benchmark for AAMI EC57 Heartbeat Classification: Assessing the Diagnostic Role of Local RR-Interval Ratios**  
   *(Concise, focusing on the specific impact of normalized RR interval ratios on classification).*
