### METHODOLOGY & PIPELINE
- [x] **Preprocessing Documented:** Moving-average baseline wander filtering ($W=217$ samples, reflection padding) and local per-beat z-score normalization ($D=200$).
- [x] **Feature Extraction Documented:** 200 morphology samples + 9 canonical bidirectional RR timing features ($D=209$).
- [x] **Retrospective Scope Documented:** Bidirectional timing explicitly identified as retrospective/offline Holter analysis due to prospective interval dependency (`RR_next`).
- [x] **Record-Level Split Documented:** Canonical de Chazal split (16 Train / 6 Validation / 22 Held-Out Test).
- [x] **Leakage Prevention Documented:** Zero inter-patient beat shuffling; zero exposure of validation/test data to training scalers or class weights.
- [x] **Model Configuration Documented:** `RandomForestClassifier(n_estimators=200, max_depth=30, min_samples_split=5, min_samples_leaf=2, max_features='sqrt', class_weight='balanced', random_state=42)`.
